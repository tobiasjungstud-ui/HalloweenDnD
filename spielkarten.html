Spielkarten

Pro Figur zwei Karten mit denselben Werten, einmal als Mann, einmal als Frau. Dazu die Gegnerkarte von Graf Vaskir. Die Werte stimmen mit dem Charakterblatt der Kurzfassung überein.

  1. „Prompt kopieren“ klicken.
  2. In ChatGPT einen neuen Chat öffnen, einfügen, abschicken.
  3. Für die nächste Karte im selben Chat weitermachen — so bleibt der Stil gleich.

Text auf der Karte: Bildmodelle verschreiben sich manchmal. Stimmt ein Wort nicht, im selben Chat nachschieben: „Same card, but fix the spelling: …“. Die Namenszeile bleibt absichtlich leer zum Ausfüllen.
